Files:
- `index.html` — Home page
- `projects.html` — Projects/Work page
- `about.html` — About/Contact page
- `wireframe.png` — wireframe/site plan image

Wireframe design notes:
- Color palette idea: lavender (#A78BFA), light blue (#93C5FD), mint (#A7F3D0), dark slate text (#334155), and a light gray background (#F3F4F6).
- Font idea: Poppins for headings and Open Sans for body text.
- CSS is intentionally not included yet.

All three HTML pages use the same navigation with relative links.
## Accessibility and Visual Design

### Accessibility
I checked all three pages with WAVE. Each page showed 0 errors and 0 contrast errors, including the About/Contact page after I added the form.

- I added labels to identify each contact form field.
- I used a fieldset and legend to group the form fields.
- I made the fields required and used email validation to help users correct missing or incorrect information.

The contact form is a practice form and does not send messages.

### Gestalt Principles
- Proximity: I kept each project title and description together inside its card so visitors can see which information belongs together.
- Similarity: I used matching colors, shapes, and spacing for the project cards so they look related.

### Consistent Colors
All three pages use the same stylesheet and color palette.
